> Sitio web oficial de presentación comercial y demostración de producto para **NeoFluid3D**.

## 💎 Identidad Visual y Sistema de Diseño

- **Paleta de Color**:
  - `Celeste Neón`: `#00F0FF` (Dominio del fluido y brillo primario activo)
  - `Verde Neón`: `#39FF14` (Estructura de cálculo y acento secundario)
  - `Fondo Oscuro`: `#030708`
- **Tipografía**:
  - **Neo**: `Poppins` (Bold / Black)
  - **Fluid³D**: `JetBrains Mono` (Bold / Regular)
- **Criterio Estético**:
  - Precisión técnica y estética de ingeniería.
  - Interactividad con respuesta visual inmediata.
  - Textura sutil estilo CRT con iluminación volumétrica de neón.

---

## 🚀 Arquitectura y Componentes

- **Arquitectura Monolítica sin Dependencias**: Aplicación web de una sola página (HTML5 / CSS3 / JavaScript ES6+) lista para producción.
- **Interactividad Acelerada por Hardware**:
  - Cursor interactivo con seguimiento suave y cambios de estado según el elemento.
  - Vistas previas de simulación procedimentales ejecutadas en canvas sin impacto en el rendimiento.
  - Animaciones de revelado reactivas mediante Intersection Observer.
- **Estructura de Secciones**:
  1. **Hero**: Símbolo de marca, propuesta de valor estratégica e indicadores de rendimiento.
  2. **La Base**: Desglose arquitectónico del motor fundacional en GPU.
  3. **Demostraciones en Video**: Tres espacios preparados para clips de simulación en formato MP4 o WebM con vista previa procedimental.
  4. **Posibilidades y Sectores de Aplicación**: Gemelos digitales industriales, prototipado rápido para ingeniería pre-CFD, simuladores de entrenamiento en VR/AR, efectos visuales/producción virtual y licenciamiento de motor B2B.
  5. **Capacidades Analíticas (Modos de Render)**: Isosuperficie volumétrica, nube de partículas SPH, red de tensión superficial y campo de velocidades euleriano.
  6. **Hoja de Ruta**: Proyección de evolución técnica y comercial en cinco fases.
  7. **Contacto Empresarial**: Formulario para consultas comerciales con notificaciones flotantes integradas.
