# 🎬 NeoFluid3D: Guía para Archivos de Video

Coloca aquí tus grabaciones o demostraciones del simulador en formato MP4 o WebM para visualizarlas en las tarjetas de la página.

### Especificaciones Recomendadas

- **Formato**: `MP4` (códec H.264 / AVC para compatibilidad universal en navegadores) o `WebM` (códec VP9 / AV1).
- **Resolución**: `1920x1080` (relación de aspecto 16:9) o `1280x720`.
- **Tasa de Cuadros**: `60 FPS` (ideal para apreciar la fluidez física) o `30 FPS`.
- **Audio**: Sin pista de audio (o silenciado).
- **Tasa de Bits (Bitrate)**: `4 a 8 Mbps` (equilibrio óptimo entre calidad visual y velocidad de carga web).

### Nombres de Archivo Predeterminados

1. `demo_mesh_reconstruction.mp4`: Demostración de reconstrucción volumétrica de malla fluida.
2. `demo_particle_dynamics.mp4`: Demostración de partículas SPH y colisión con obstáculos.
3. `demo_vector_fields.mp4`: Demostración del campo vectorial de velocidades.
